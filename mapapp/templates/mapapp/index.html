사용 방법

  1. 지도에서 토지 선택: 지도 위의 토지를 클릭하면 해당 필지가 초록색으로 표시되고, 오른쪽 표에 토지 정보가 추가됩니다.
  2. 주소 검색으로 토지 추가: 검색창에 도로명주소, 지번주소, 또는 도로명을 입력한 뒤 검색 버튼을 누르세요. 검색 결과 목록에서 원하는 주소를 클릭하면 해당 토지가 지도에 표시되고 표에 추가됩니다.
  3. 표에서 토지 확인: 표의 행을 클릭하면 해당 토지 위치로 지도가 이동합니다.
  4. 토지 강조 표시: 표의 행을 클릭하면 행이 강조 표시되고, 지도 위의 해당 토지가 주황색으로 변경됩니다. 다시 클릭하면 기본 초록색으로 돌아갑니다.
  5. 개별 토지 해제: 각 행의 해제 버튼을 누르면 해당 행이 삭제되고, 지도 위의 표시도 제거됩니다.
  6. 전체 해제: 모두 해제 버튼을 누르면 선택된 모든 토지와 표 데이터가 삭제됩니다.
  7. 엑셀 내보내기: 엑셀 파일 내보내기 버튼을 누르면 현재 표의 데이터를 Excel 파일로 저장할 수 있습니다.

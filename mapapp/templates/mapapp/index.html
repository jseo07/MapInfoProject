사용 방법

  1. 토지 선택
    지도에서 클릭하거나 드래그 선택으로 여러 필지를 선택합니다.
  2. 주소 검색
    주소 또는 도로명을 입력 후 검색 → 결과를 클릭하면 토지가 추가됩니다.
  3. 그룹 설정
    그룹을 선택한 뒤 토지를 선택하면 해당 그룹으로 저장됩니다.
  4. 토지 확인 및 강조
    표의 행을 클릭하면 지도에서 위치로 이동하며 강조 표시됩니다.
  5. 삭제
    개별 삭제: 해제 버튼
    전체 삭제: 모두 해제
  6. 데이터 관리
    엑셀 파일로 내보내거나, 기존 데이터를 가져올 수 있습니다.
